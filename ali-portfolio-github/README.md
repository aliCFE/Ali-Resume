# موقع علي محمد الشخصي (Portfolio)

موقع شخصي كامل مبني من السيرة الذاتية، بلغة HTML وCSS وJavaScript خالصة — بدون أي مكتبات خارجية، وبدون أي طلبات إنترنت. يشتغل مباشرة بفتح الملف، ويشتغل أوفلاين.

## كيف تفتحه

اضغط مرتين على ملف `index.html`. هذا كل شيء.

## الملفات

```
portfolio/
├── index.html                  هيكل الصفحة (الأقسام والأيقونات)
├── assets/
│   ├── css/style.css           كل التصميم: الألوان، الأقسام، الوضع الليلي/النهاري، RTL
│   ├── js/data.js              ← كل المحتوى هنا (عربي + إنجليزي)
│   ├── js/app.js               الرسم والحركات والتفاعل
│   ├── images/ali.jpg          الصورة الشخصية
│   └── files/Ali_Mohammed_CV.pdf   ملف السيرة الذاتية للتحميل
└── README.md
```

## تعديل المحتوى

**كل النصوص موجودة في ملف واحد فقط: `assets/js/data.js`** — لا تحتاج تفتح أي ملف ثاني.

كل نص مكتوب بالشكل التالي، الإنجليزي والعربي جنب بعض:

```js
role: { en: 'Founder & CEO', ar: 'المؤسس والرئيس التنفيذي' },
```

عدّل النص بين علامات التنصيص فقط، واحفظ الملف، وحدّث الصفحة في المتصفح.

داخل `data.js` راح تلاقي هذه الأقسام:

| القسم | وين تعدّله |
|---|---|
| الاسم والبريد والهاتف واللينكدإن | `CV.profile` |
| الألقاب المتحركة في الأعلى | `CV.profile.roles` |
| الأرقام (سنوات الخبرة، الطلاب...) | `CV.stats` |
| نبذة عني | `UI.en['about.p1']` و `UI.ar['about.p1']` |
| الخبرات العملية | `CV.experience` |
| المشاريع | `CV.projects` |
| المهارات | `CV.skills` |
| الدراسة والشهادات | `CV.education` و `CV.certifications` |
| الإنجازات واللغات | `CV.achievements` و `CV.languages` |
| بيانات التواصل | `CV.contactCards` |

### إضافة خبرة جديدة

انسخ أي عنصر موجود داخل `CV.experience` والصقه، وعدّل قيمه:

```js
{
  role:    { en: 'Job Title', ar: 'المسمّى الوظيفي' },
  company: 'Company Name',
  period:  { en: 'Jan 2027 – Present', ar: 'يناير ٢٠٢٧ – حتى الآن' },
  current: true,        // يضيف نقطة خضراء نابضة "الدور الحالي"
  concurrent: true,     // يضيف شارة "بالتوازي مع دور آخر"
  featured: true,       // يميّز البطاقة بإطار ملوّن
  tags: ['Leadership', 'PHP'],
  bullets: [
    { en: 'What you did.', ar: 'ما الذي أنجزته.' },
    { en: 'An award you got.', ar: 'جائزة حصلت عليها.', award: true }
  ]
}
```

ملاحظة: العناصر تظهر بنفس ترتيبها في الملف — ضع الأحدث في الأعلى.

### إضافة مشروع جديد

انسخ أي عنصر داخل `CV.projects`:

```js
{
  id: 'my-project',              // اسم فريد بدون مسافات
  name: 'example.com',
  cats: ['nova', 'web'],         // للفلاتر: nova / web / software / games
  icon: 'cart',                  // الأيقونات المتاحة في أعلى app.js
  accent: 'emerald',             // violet / cyan / emerald / amber / rose / sky
  link: 'https://example.com',   // احذف هذا السطر إذا ما كو رابط
  featured: true,                // يضيف شارة Nova
  tagline: { en: 'Short line', ar: 'سطر قصير' },
  tech: ['PHP', 'MySQL'],
  bullets: [
    { en: 'First point — يظهر أيضاً في بطاقة المشروع.', ar: 'النقطة الأولى.' }
  ]
}
```

أول نقطة في `bullets` هي التي تظهر على البطاقة، وباقي النقاط تظهر عند فتح المشروع.

## تغيير الصورة الشخصية

الصورة موجودة في `assets/images/ali.jpg` (مقصوصة مربّعة بقياس 640×640). لتبديلها، ضع صورة مربّعة جديدة بنفس الاسم والمسار.

إذا كانت الصورة الجديدة غير مربّعة، عدّل السطر التالي في `assets/css/style.css` لضبط الجزء الظاهر منها:

```css
.orbit__photo { object-position: 50% 16%; }
```

الرقم الثاني يتحكم بالارتفاع: كلّما صغّرته ظهر الجزء الأعلى من الصورة أكثر.

## تحديث ملف الـ CV للتحميل

استبدل الملف `assets/files/Ali_Mohammed_CV.pdf` بالنسخة الجديدة مع الإبقاء على نفس الاسم — زر "السيرة الذاتية" راح يشتغل تلقائياً.

## الرفع على الإنترنت

الموقع ملفات ثابتة فقط، لذلك يشتغل على أي استضافة:

**Hostinger:** ارفع كل محتويات مجلد `portfolio` إلى `public_html` عبر مدير الملفات. خلص.

**GitHub Pages:** ارفع الملفات إلى مستودع، ثم Settings ← Pages ← اختر الفرع `main` والمجلد `/root`.

**Netlify / Vercel:** اسحب مجلد `portfolio` وأفلته في صفحتهم الرئيسية.

## مميزات مبنية داخل الموقع

- تبديل عربي/إنجليزي كامل مع قلب الاتجاه (RTL) — يُحفظ في المتصفح
- وضع ليلي ونهاري — يتبع إعداد نظامك تلقائياً أول مرة، ثم يُحفظ اختيارك
- شاشة تحميل، ومؤشر فأرة مخصّص، وشريط تقدّم للتمرير
- خلفية متحركة (شبكة نقاط على Canvas) وكرات ضوئية بتأثير Parallax
- تأثير كتابة للألقاب، وعدّادات رقمية تتحرك عند الوصول لها
- خطّ زمني للخبرات يمتلئ تدريجياً مع التمرير
- فلاتر للمشاريع ونافذة تفاصيل لكل مشروع (تُغلق بزر Esc)
- نموذج تواصل يفتح تطبيق البريد لديك، ونسخ البريد/الهاتف بضغطة
- متجاوب من عرض ٣٢٠ بكسل فما فوق
- يحترم إعداد `تقليل الحركة` في النظام، ويدعم التنقّل بلوحة المفاتيح
- تنسيق خاص للطباعة (Ctrl+P يطبع نسخة نظيفة)
